# 本地成长档案设计

## 目标与范围

在不接入 Supabase 登录和云端同步的前提下，让同一浏览器中的孩子可以持续查看自己的学习变化。成长记录从单个汇总数字升级为可按日期和学习项追溯的本地档案。

本次实现覆盖：单词听写、句子跟读、句式确认、剧集完成、今日变化、最近七天变化，以及已学会的具体单词、句子和句式。

本次不覆盖：跨设备同步、多孩子档案、云端备份、自动语音转写服务、复杂的间隔复习算法和导出/清除成长记录。

## 存储边界

前端新增 `ProgressRepository` 接口。首个实现使用版本化 `localStorage`，键名使用产品命名空间并包含数据版本。接口负责读取、写入、记录事件和从事件派生成长摘要。

页面不直接访问 `localStorage`。未来接入 Supabase 时新增云端实现，并保留相同的读写契约；现有页面和学习规则不需要重写。

数据仅保存在当前浏览器。清除站点数据、无痕模式失效或更换设备都会失去本地档案；页面在首次使用时明确但不过度强调这一限制。

## 数据模型

每一条学习活动保存为不可变的 `LearningEvent`：

- `id`：本地生成的唯一标识。
- `occurredAt` 与 `day`：ISO 时间与本地日期键，用于按天归档。
- `kind`：`vocabulary_mastered`、`sentence_mastered`、`pattern_mastered`、`episode_completed` 或 `practice_completed`。
- `item`：稳定的内容 ID，以及英文、中文和可展示标题快照。
- `episodeId`：来源剧集；练习事件同时保存正确与否及练习类型。

事件不会因为同一内容重复练习而重复产生“首次学会”。对同一个内容保留一份 `MasteryItem` 派生状态：首次学会日、最近练习日、正确练习次数、总练习次数和熟练度。熟练度只用于温和标签（刚认识、越来越熟、很熟悉），不用于排名或压力展示。

## 学会规则

| 内容 | 首次学会条件 | 后续更新 |
| --- | --- | --- |
| 单词 | 一次单词听写判定正确 | 每次单词练习更新最近练习日与熟练度 |
| 句子 | 跟读判定正确，或人工修正为正确 | 每次跟读更新最近练习日与熟练度 |
| 句式 | 孩子在展开的句型卡片上点击“我会这个句式” | 再次确认只更新最近练习日 |
| 剧集 | 点击“完成本集学习” | 重复点击不重复增加已学剧集数 |

浏览单词、展开台词或播放声音不会被视为“学会”。这样成长档案反映的是完成的学习行为，而不是页面浏览量。

## 页面与交互

成长记录页保持现有云朵绘本风格，并分为三个可访问区域：

1. `今日小成长`：展示今天新学会的单词、句子、句式和练习次数；没有活动时提供“去学习”入口。
2. `这一周的小脚印`：最近七天的日期小爪印。每个日期显示活动量；点击日期后更新下方当日明细，不使用成人化的排名、分数或强制目标。
3. `我的学习收藏`：单词、句子和句式三个筛选项。每项列出内容、中文释义或说明、首次学会日期、最近练习日期和温和的熟练度标签。

现有四张统计卡仍保留为总览，但改为可点击的入口：已学剧集打开已完成剧集清单；累计单词、练习次数和需要复习分别切换到对应的明细或筛选状态。

句型卡片增加明确的“我会这个句式”按钮。点击后就地反馈“已经收进今天的成长记录”，不会跳转或打断阅读。

## 数据流与错误处理

单词和句子仍先调用现有 API 获得判定结果。结果返回后，前端将练习活动写入本地成长档案；正确结果会同时更新对应的掌握状态。人工修正成功后也更新本地掌握状态。

写入本地存储失败时，学习结果照常显示，但在当前操作位置提示“这次学习还没有记进成长记录，请检查浏览器存储空间后再试”。读取到损坏数据时，仓库忽略损坏数据并创建新的空档案，避免阻塞学习页面。

## 验收与测试

- 首次正确完成单词听写后，成长页显示该单词及当天日期；重复答对不会重复计入新学单词。
- 跟读正确与人工修正均能记录句子掌握。
- 点击句型确认后，成长页显示对应句式；重复确认不重复计数。
- 完成本集后，刷新页面仍显示已学状态和当日事件。
- 最近七天可选中任一天，并仅展示该日对应明细。
- 空成长档案有明确的下一步入口；存储异常在动作附近显示错误。
- 覆盖桌面、iPad 和窄屏手机的触控区域、长句折行及筛选可访问性。

## 迁移路径

未来接入 Supabase 时，`ProgressRepository` 的云端实现按相同事件和掌握状态字段保存数据。首次登录可询问是否导入当前设备的本地记录；该迁移不属于本次实现范围。
