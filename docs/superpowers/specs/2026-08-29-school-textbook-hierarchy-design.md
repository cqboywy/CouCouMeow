# 校内同步教材层级设计

**目标：** 校内同步按真实教材目录组织，使同一本教材的多个 Unit、不同年级教材都能清楚扩展，同时保留已完成的逐页学习闭环。

## 教材依据

PEP 四年级上册目录有 6 个 Unit：`Helping at home`（2–13 页）、`My friends`（14–25 页）、`Places we live in`（26–37 页）、`Helping in the community`（38–49 页）、`The weather and us`（50–61 页）和 `Changing for the seasons`（62–73 页）。74 页开始总复习，附录从 78 页开始。

## 信息架构

```
校内同步
└── 教材 PEP 四年级上册
    ├── Unit 1 → 单元路线 → 页组 → 课本页
    ├── Unit 2 → 单元路线 → 页组 → 课本页
    └── Unit 3–6 → 暂无内容时显示“正在整理”，不可进入学习页
```

校内同步首页只显示当前教材、一个“继续学习”操作、六个 Unit 的紧凑列表和当前 Unit 的页组路线。每次只展开一个 Unit；空 Unit 不提供假的练习入口。

## 数据边界

- `TextbookPage` 归属 `unitId` 与 `moduleId`。
- `TextbookUnitModule` 表示 Unit 内连续的教材页组，例如 `单元导入`、`Part A`、`Part B`、`阅读与项目`。
- `TextbookUnitOverview` 描述 Unit 名称、大问题、印刷页范围和已整理页数。
- 校内进度使用 `pageId`、`unitId` 和 `textbookId` 聚合；课外数据不读取此存储键。
- 当前页面优先定位到当前 Unit 的首个未完成页；若当前 Unit 完成，定位下一有内容 Unit 的首个页。

## 界面与交互

1. 顶部教材选择为一个紧凑按钮；后续加入年级时，先选教材，不在首页同时铺开多个年级。
2. Unit 列表展示 `Unit 编号、英文主题、中文主题、页数进度`；只有当前 Unit 展开页组。
3. 页组内按真实印刷页显示。页行状态为“已完成 / 正在学习 / 可以学习 / 正在整理”。
4. 点击有内容页进入现有逐页学习页，保留中文开关、重点、朗读、开口挑战、稍后再学、小检查和收尾。
5. Unit 页面只显示该 Unit 的“稍后再学”数量；课外动画仅在最底部作为次级辅助。逐题复习入口会在 Unit 逐页数据补齐后接入。

## 取舍

- 保留旧 `CurriculumLesson` 和 `SchoolLesson` 仅用于没有逐页内容的兼容入口；不再在主界面显示六课时。
- 不显示 Unit 3–6 的假内容；以“正在整理”提示，避免孩子误以为可以开始。
- 先实现 Unit 1 和 Unit 2 的结构与导航；Unit 2 在逐页数据补齐前显示为准备中，不进入旧练习流。

## 验收

- 当前校内首页不会把不同 Unit 的页面混在一条路线中。
- Unit 1 第 3、4 页仍能进入完整逐页学习。
- 新增 Unit 2 时只新增 Unit 元数据与页面数据，不需改变首页结构。
- 进度和复习能按 Unit 统计，且不影响课外动画记录。
