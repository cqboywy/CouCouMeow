# 校内同步逐页学习整合设计

**目标：** 将 PEP 校内同步从“课时 + 三个独立步骤”的任务界面，改为以教材印刷页为中心的学习路径；复用已完成的第 3、4 页文字学习原型，同时继续和课外动画、成长记录保持数据隔离。

## 体验结构

校内同步分为两层。

### 1. 单元页：书架与路线图

单元页不承载详细学习内容，只回答三个问题：正在学哪本书和哪个单元、下一页是什么、已完成与待复习多少。

- 顶部显示教材和当前单元：`PEP 四年级上册 · Unit 1 Helping at home`。
- 单元切换仅展示有真实内容的单元；没有内容的单元不作为可点的空入口。
- 一个主操作：`继续学习`，始终指向当前未完成教材页。
- 页面路线以印刷页码为单位，显示完成、当前、可学习三种状态；状态除颜色外附带文字。
- 只显示两个轻量指标：`已完成 X / Y 页` 与 `稍后再学 X 条`。
- 页面底部可放一张次级“课外动画辅助”推荐卡，但不能抢占校内主路径。

### 2. 教材页：一个可完成的学习闭环

每一页由 PDF 的印刷页码和真实内容驱动，而不是由抽象“第几课”驱动。

1. 页头：教材、单元、印刷页码、简短中文主题、返回单元。
2. 原文区：按课本栏目标识组织，如 `Look and think`、`Let's talk`、`Draw and say`。英文是主内容。
3. 理解辅助：中文显示开关固定在当前页面底部；重点词、词块、常用表达在原句中高亮，点击后在当前句旁显示说明和朗读按钮。
4. 练一练：本页重点句的听读、词块提示、看中文说英文；不跳到脱离上下文的独立任务页。
5. 小检查：紧跟练习，2–4 道本页题目；完成后记录页面进度。
6. 收尾：显示本页掌握内容、稍后再学条目、下一页入口。

单元末尾额外提供 `Unit 小复习`，汇总本单元错词、错句和常用表达；它不替代每页的小检查。

## 内容与数据模型

新增或迁移后的教材内容以 `TextbookPage` 为核心：

- `textbookId`、`unitId`、`printedPage`、`title`、`chineseTitle`
- 有序 `sections`，包含栏目标题、原句、中文提示和可点击重点项
- `focusItems`，标记来源：正文、Appendix 2 单词、Appendix 3 词汇表、Appendix 4 常用表达
- `practicePrompts`、`checkQuestions`、`nextPage`

现有校内 `localStorage` 仓库继续独立于课外动画。事件从“完成某课时”扩展为“完成某教材页”；练习正确/错误、稍后再学、掌握的词和句仍保存在校内键中。旧课时 ID 仅用于迁移兼容，不再驱动界面。

## 可复用与淘汰

### 保留并复用

- 校内、课外独立的进度、错题、复习与成长统计。
- `useEnglishSpeech` 的英文声音预热、播放状态和失败提示逻辑。
- 本地复习队列、已掌握词句集合与成长记录展示。
- 现有响应式卡片、44px 以上触控目标与轻量校内视觉风格。

### 迁移或淘汰

- `学课本 / 练一练 / 小检查` 的顶部三标签不再作为独立页面导航，改为教材页内的顺序模块。
- “六课时”只保留为旧进度数据兼容信息；面对孩子的路线显示教材页码。
- “请打开课本第 X 页”降级为来源提示，不再是核心学习动作。
- 不在单元首页重复放大教材标题、课时数和多个统计卡。
- 只有颜色的进度状态改为颜色 + 文本状态。

## 迁移顺序

1. 把第 3、4 页原型提炼为可复用的页面内容和组件模式。
2. 建立 Unit 1 的印刷页路线及“继续学习”定位。
3. 将页面完成、稍后再学、练习和小检查写入现有校内进度仓库。
4. 以单元页替换旧的课时入口；保留旧路由重定向，避免现有链接失效。
5. 补 Unit 小复习和校内成长记录中的“按单元 / 按页面”查看。

## 验收标准

- 校内首页一屏能看出当前单元、下一页、页数进度和待复习数，不出现成组的练习面板。
- 第 3、4 页均可从 Unit 1 路线进入，并具备中文开关、重点提示、朗读、开口挑战、稍后再学和小检查。
- 完成页面后刷新仍保留校内进度；课外动画的数据和统计不被改变。
- 手机上中文开关、朗读状态和重点说明都在当前阅读位置可见，不遮挡正文。
- 旧校内入口仍可打开对应内容或被明确引导至相应教材页。
