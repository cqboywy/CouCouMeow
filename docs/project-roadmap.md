# 凑凑喵英语乐园项目路线图

## 项目定位

凑凑喵英语乐园（CouCouMeow English Land）是一套面向一名 10 岁女孩、以 iPad 为主要学习设备的家庭英语巩固系统。家长可先在本地播放 Little Fox 动画，孩子随后进入网站学习对应剧集的台词、词汇和句型，并完成听写与跟读。系统自动沉淀错词、错句和复习任务。

项目采用分阶段交付。每个阶段必须形成可独立运行和验证的成果，未通过本阶段验收前不进入下一阶段。

## 阶段 0：工程基础骨架

### 目标

建立可部署、可测试、可扩展的前后端与数据基础，不提前实现完整业务页面。

### 任务

1. 建立 pnpm monorepo，并统一根目录命令。
2. 初始化 React、Vite 和 TypeScript 前端。
3. 初始化 Python 3.12、FastAPI 和 uv 后端。
4. 建立 Supabase 内容表、学习表、索引、事务函数和 RLS 策略。
5. 建立支持 `single`、`batch` 和 `--dry-run` 的本地内容入库工具骨架。
6. 定义 DeepSeek 内容生成接口、语音转写接口和 Supabase 数据访问接口。
7. 建立 FastAPI OpenAPI 到 TypeScript 客户端的生成流程。
8. 建立“凑凑喵的绘本乐园”设计令牌、触控规范和基础组件边界。
9. 配置环境变量模板、容器配置、格式检查、类型检查、测试和 GitHub Actions。
10. 编写本地开发、数据库迁移、部署和内容入库的中文文档。

### 验收标准

- 前端和后端可以独立启动，前端能访问后端健康检查接口。
- 数据库可以从空 Supabase 项目完整迁移。
- RLS 测试证明用户只能访问自己的学习数据。
- 入库工具可以通过 `single` 和 `batch --dry-run` 解析测试字幕。
- 不配置真实 Supabase、DeepSeek 或语音服务密钥时仍能运行单元测试。
- CI 自动完成格式、类型、单元测试和构建检查。
- 项目中不存在真实密钥、MP4 或真实 SRT 素材。

### 本阶段不包含

- 完整首页和学习业务页面。
- 真实 DeepSeek 内容生成调用。
- 真实语音转写服务绑定。
- 视频上传或在线播放。

## 阶段 1：MVP 学习闭环

### 目标

打通“观看本地动画、进入剧集、学习内容、完成练习、自动沉淀错误”的日常学习闭环。

### 任务

1. 实现家长邮箱登录、登录保持和单个孩子档案。
2. 实现猫咪主题首页、今日继续学习入口和 Level 1–9 折叠列表。
3. 只展示状态为 `published` 的人工校验剧集。
4. 实现剧集详情页、双语台词、单句发音、词汇表和句型知识点。
5. 实现“看中文默写英文”模式。
6. 实现“听发音默写英文”模式。
7. 实现标准化拼写比对、温柔反馈和错词自动沉淀。
8. 实现浏览器录音、后端语音转写接口和句子相似度判定。
9. 实现错句自动沉淀及人工修正识别结果。
10. 实现已学状态、累计单词数和练习次数统计。
11. 完成单集入库、批量入库、断点续跑、内容校验和人工发布流程。
12. 完成 iPad 竖屏、iPad 横屏、手机和电脑响应式适配。
13. 完成登录、剧集学习、两种听写和跟读流程的端到端测试。
14. 将前端、后端和 Supabase 部署到公网环境。

### 验收标准

- 孩子能在 iPad 上完成一集内容的浏览、听写和跟读。
- 错词、错句、人工修正和练习次数准确写入云端。
- 未发布剧集不会出现在网站中。
- 刷新或更换设备后，登录用户仍能读取自己的进度和错题。
- 核心交互符合大触控区域、低刺激反馈和无障碍对比度要求。

## 阶段 2：智能记忆闭环

### 目标

将历史错误转换为每日自动复习任务，建立可解释的防遗忘闭环。

### 任务

1. 实现云端生词本和句子错题本。
2. 展示错误次数、易错频率、最近错误时间和掌握状态。
3. 实现错词与错句的 1、3、7 天复习调度。
4. 实现“今日复习”入口和到期内容列表。
5. 实现句子错题专项练习。
6. 实现根据英文句子自动挖空的精听练习。
7. 根据复习结果更新复习阶段、掌握状态和下次复习时间。
8. 实现进度、掌握量、薄弱项和学习趋势仪表盘。
9. 测试时区、跨日、漏学、重复错误和人工修正场景。

### 验收标准

- 系统每日自动给出到期复习内容，无需家长手工整理。
- 正确与错误结果会稳定推进或重置复习阶段。
- 仪表盘数据能够追溯到具体练习记录。
- 同一错词或错句不会产生互相冲突的复习计划。

## 阶段 3：双体系与智能提升

### 目标

连接课外动画与人教版 PEP 小学英语，并提供受控的智能对话、内容推荐和家庭报告。

### 任务

1. 建立 PEP 年级、册次、单元、课次、词汇和句型数据模型。
2. 建立 Little Fox 剧集与 PEP 知识点的映射关系。
3. 实现动画学习与校内同步双入口。
4. 实现只使用已学词汇和句型的 AI 情景口语对话。
5. 建立儿童对话安全边界、话题限制、超范围拒绝和家长可见记录策略。
6. 根据错误率、掌握度、练习表现和学习进度推荐合适 Level。
7. 自动生成周学习报告和月学习报告。
8. 为报告中的指标提供定义、数据来源和异常说明。
9. 在内容规模稳定后加入 Level 管理、搜索、收藏及已学/未学筛选。
10. 为大规模入库增加进度显示、失败恢复、质量抽检和发布批次管理。

### 验收标准

- 动画内容和 PEP 内容能通过明确知识点建立关联。
- AI 对话不会主动使用超出当前已学范围的核心表达。
- 推荐结果可以解释使用了哪些学习证据。
- 周报和月报的数据可追溯且不会混入其他用户数据。

## 阶段推进规则

- 每个阶段单独编写设计规格和实施计划。
- 当前只执行阶段 0；阶段 1–3 的路线图不是提前实现授权。
- 数据库迁移保持向前兼容，不用手工修改生产数据库。
- 新功能必须同时包含测试、错误状态、儿童友好文案和 iPad 验证。
- 猫咪主题是产品体验的一部分，不能在功能开发中降级为零散 Emoji 或装饰贴纸。
